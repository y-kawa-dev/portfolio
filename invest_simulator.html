// Background

開発のこだわり：AIと指標の融合

単純なチャートビューアではなく、実際の投資判断プロセスを再現することを目指しました。 ルールベースのテクニカル指標（RSI / MACD）と、Gemini APIによる自然言語推論を組み合わせることで、 「なぜその判断を下したか」が説明できる透明性の高い自動売買エンジンを実装しています。

また、過去データを使ったバックテスト機能では日経225 Buy&Holdとの比較も行え、 戦略の実用的な有効性を定量的に検証できます。

🤖
AI自動売買（Gemini）
Gemini APIが30銘柄のRSI・MACD・トレンドを総合分析し、BUY / SELL / HOLDの判断と理由を自然言語で提示。コンセンサスモードで2AIが合意した場合のみ実行する安全弁も実装。
📊
バックテストエンジン
テクニカル戦略とAI戦略それぞれで過去データを遡ってシミュレーション。最大ドローダウン・勝率・日経225超過収益を算出し、戦略の実力を可視化。
🔔
リスク管理機構
損切りライン・利確ライン・トレーリングストップを設定可能。サーキットブレーカー機能で総資産が一定水準を下回ると自動売買を強制停止。
🌐
リアルタイム株価
yfinanceで日本市場の株価をリアルタイム取得。取引時間判定・前日比・ローソク足チャートを自動表示。市場時間外は注文ボタンを自動無効化。

// Key Features

主要機能の詳細

01

AI自動売買 — Gemini APIとの連携

最大30銘柄のRSI・MACD・価格トレンド・保有状況を一括でGemini APIに送信。AIは各銘柄に対してBUY / SELL / HOLDの判断と確信度（HIGH / MED / LOW）、理由を返答。コンセンサスモードでは2回の独立した分析結果が一致した場合のみ実行し、誤シグナルを抑制します。

02

AIバックテスト — 戦略の定量検証

AI戦略と同一ルール（RSI/MACD/トレーリングストップ/セクター分散）で過去1〜5年のデータを遡りシミュレーション。最終資産・勝率・最大ドローダウン・日経225超過収益を算出し、資産推移グラフで戦略を可視化。銘柄別成績テーブルと全取引ログも確認可能です。

03

AIトレンド自動更新

全30銘柄の直近パフォーマンスをAIが分析し、注目度の高い銘柄を自動選択する機能。手動で全銘柄を監視するのではなく、AIに「今注目すべき銘柄」を絞り込んでもらうことで、無駄なAPI呼び出しとノイズを削減します。

04

リスク管理 — 3層の安全弁

① 銘柄ごとの損切り（Stop Loss）/ 利確（Take Profit）ライン設定。② 最高値からの下落率で自動損切りするトレーリングストップ（デフォルト8%）。③ 総資産が初期資金から一定水準（デフォルト-15%）を下回った際に自動売買を強制停止するサーキットブレーカー。
